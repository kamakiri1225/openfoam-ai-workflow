# session_019 - スライド構成をAI活用ワークフロー中心に再設計

**日時**: 2026-05-09  
**対象**: `LLM001/docs/reveal_llm001_workflow.html`

---

## 要望

スライドの説明が分かりやすくないため、流れが伝わるように構成を練り直したい。

本当に伝えたいこと:

- ポンチ絵から YAML ファイルは AI に作ってもらう。
- YAML からメッシュ作成するプログラムは、テンプレート的にうまく動くものを AI に作ってもらう。
- OpenFOAM の解析設定生成も同様に、AIが作ったプログラムで YAML から生成する。
- その流れが分かる資料にしたい。

## 対応

`reveal_llm001_workflow.html` を再構成した。

新しい中心ストーリー:

```text
ポンチ絵
  -> AIがYAML化
  -> AIが生成プログラムを作る
  -> プログラムがgmshメッシュとOpenFOAM設定を生成
  -> OpenFOAMで解析
  -> ParaViewで結果確認
  -> 必要ならYAMLやポンチ絵へ戻る
```

主な変更:

- 「作ったファイルの説明」よりも、「人・AI・プログラム・OpenFOAMの役割分担」を先に説明。
- swimlane形式で誰が何を担当するかを追加。
- YAMLを中心にする理由を追加。
- AIに作ってもらうものを `YAML` と `生成プログラム` に明確化。
- gmsh生成器とOpenFOAM辞書生成器の役割を別々に説明。
- 計算結果デモ画像を結果確認スライドに配置。
- 横方向は章移動、下方向は章内詳細の構成を維持。
