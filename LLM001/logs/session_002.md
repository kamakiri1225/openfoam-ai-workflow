# session_002 - ポンプCAD差分モデル修正履歴

**日時**: 2026-05-09  
**対象**: `LLM001/geometry/LLM001_pumpA.py`  

---

## ユーザー要望

- ポンプとタンクはいずれもソリッドとして扱う。
- タンクからポンプをCADブーリアン差分で引いて、流体領域モデルを作成する。
- `LLM001/img/20260508_ポンチ絵から結果.png` の右側イメージのように、タンク上面にポンプA/Bの円形パッチが見えるモデルにしたい。
- 現状は左側のように、ポンプ位置に細かいメッシュ領域が見えるだけで目的を達成していない。

## 問題点

- 以前のモデルでは、ポンプを中空円筒として作成していたため、タンクから差し引いたときに中央ボアが流体領域として残っていた。
- そのため、意図した「ポンプソリッドを引いた障害物形状」になりにくかった。
- また `pump_h = Lz - 0.010` としていたため、ポンプ上面がタンク上面 `z=Lz` より10mm低い位置にあった。
- その結果、上から見たときにタンク上面へ円形パッチが現れず、細かいメッシュ領域だけが見える状態になっていた。
- `pump_bottom` 側の水平面が `pumpWall` に分類されており、本来の `pumpA_outlet` / `pumpB_inlet` に境界条件が割り当てられていなかった。

## 修正方針

- ポンプA/Bは中空円筒ではなく、外径そのままのソリッド円柱として作成する。
- ポンプはタンク底面から10mm浮かせる。
- ポンプ上面はタンク上面 `z=Lz` まで届かせる。
- 流体領域は `タンク(Box) - ポンプA(ソリッド円柱) - ポンプB(ソリッド円柱)` とする。
- ポンプA/Bの水平面は、上面・下面ともに流出/流入パッチへ分類する。
- ポンプ円筒側面のみを `pumpWall` とする。

## 主な変更

- `pump_bottom = 0.010` を追加。
- `pump_top = Lz` を追加。
- `pump_h = pump_top - pump_bottom` に変更。
- ポンプA/Bの円柱作成を以下の考え方に変更。
  - 開始位置: `z = pump_bottom`
  - 高さ: `pump_h`
  - 上面: `z = Lz`
- `pA_inner` / `pB_inner` による中空化をやめ、`pA_solid` / `pB_solid` をそのまま差分対象にした。
- `z=pump_top` の水平面を、中心座標からの距離で `pumpA_outlet` / `pumpB_inlet` / `topWall` に分類。
- `z=pump_bottom` の水平面も、中心座標からの距離で `pumpA_outlet` / `pumpB_inlet` / `pumpWall` に分類。
- `pumpWall` には主にポンプ円筒側面が入る想定。

## 現在の意図した境界分類

- `pumpA_outlet`: ポンプAの上下面ディスク。
- `pumpB_inlet`: ポンプBの上下面ディスク。
- `pumpWall`: ポンプA/Bの円筒側面。
- `topWall`: タンク上面のうちポンプA/B以外。
- `bottom`: タンク底面。
- `sideWall`: タンク左右側面。
- `frontWall`: タンク前後側面。
